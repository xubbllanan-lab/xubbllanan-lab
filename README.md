## 🔧 我做的

### DeepSeek 对话导出助手

把 DeepSeek 的整段对话一键导出，保留标题层级、代码块、表格，清除全部 Emoji。走接口级提取，提问内容 100% 准确。

**支持**：复制纯文本 / Markdown / 富文本，下载 TXT · MD · HTML · JSON · Word(docx) · PDF，每条回答可单独导出。

```
https://raw.githubusercontent.com/xubbllanan-lab/deepseek-export-assistant/main/deepseek-export.user.js
```

👆 复制这个链接，浏览器打开即可安装（需先装 Tampermonkey）
